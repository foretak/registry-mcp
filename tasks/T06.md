## Goal
`api/main.py` (FastAPI) per `NORBIZ_SPEC.md`, with country-scoped routes:

- `GET /v1/countries` — list of supported registries.
- `GET /v1/{country}/company/{id}` — `CompanyReport`.
- `GET /v1/{country}/search?q=&limit=` — `list[SearchHit]`.
- `GET /v1/{country}/company/{id}/deadlines?today=YYYY-MM-DD` — `list[Deadline]`.
- `GET /v1/{country}/validate/{id}` — `{valid, normalized, reason}`.
- `GET /health` — `{status, version, countries}`.
- `GET /`, `/llms.txt`, `/llms-full.txt`, `/server.json` — from `static/`.
- Unknown country → 404 with hint listing `/v1/countries`. Invalid id → 400 with hint to call validate. Upstream down → 502 with hint to retry after N seconds. All errors in the D-007 format.
- Rate limit 60/min per IP (in-process token bucket is fine; header `Retry-After`).
- OpenAPI: every route has `summary`, `description` (what it's for, when to use it, what to do on failure), and a response example. Tags per country.
- Routes must dispatch via `core.registry.get_registry(country)` — no Norwegian imports in `api/`.
