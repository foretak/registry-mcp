# T08 — Usage logging and stats endpoint

Owner: Sonnet 3
Depends on: T07
Unblocks: T09, T10

## Goal
- `core/log.py` — `log_call(surface: Literal["rest","mcp"], operation: str, country: str, query: str, user_agent: str, latency_ms: int, ok: bool, error_code: str | None)` writing to a `calls` table in the same SQLite file as the cache (D-006 path). Non-blocking: never let a logging failure fail a request.
- Wire it into every REST route (middleware) and every MCP tool (decorator or FastMCP middleware). MCP user agent: take it from the HTTP request headers when on Streamable HTTP; `"stdio"` on stdio.
- `GET /v1/stats?key=<REGISTRY_MCP_ADMIN_KEY>` — 403 without the key. Returns: total calls, calls today, calls per day (last 30), split by surface, top 20 queries, distinct user agents with counts, error rate.
- `core/stats.py` — the queries behind the endpoint, reusable by T09.

## Files you own
`core/log.py`, `core/stats.py`, `api/stats.py`, `tests/test_log.py`, `tests/test_stats.py`, plus the minimal wiring lines in `api/main.py` and `mcp/server.py`.

## Files you must not touch
`core/models.py`, `core/registry.py`, `registries/`, `static/`, `DECISIONS.md`.

## Decisions that apply
D-003, D-006, D-007.

## Done-check
Start the server, make ten calls (mix of REST and MCP, at least two distinct `User-Agent` headers), then:
```
curl -s "localhost:8080/v1/stats?key=$REGISTRY_MCP_ADMIN_KEY" | python -m json.tool
```
shows `total_calls: 10`, correct top queries, ≥2 distinct user agents, and both surfaces. `curl localhost:8080/v1/stats` (no key) → 403. Tests, mypy, ruff clean. Set T08 to `review`.
