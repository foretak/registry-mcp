# T09 — Stats dashboard page

Owner: Sonnet 4
Depends on: T08
Unblocks: T10

## Goal
One URL the human opens each morning: `GET /v1/stats/dashboard?key=<ADMIN_KEY>` — a single self-contained HTML page (inline CSS/JS, no CDN) rendered from `core/stats.py` data:

- Daily calls, last 30 days (simple bar chart via inline SVG).
- MCP vs REST split.
- Unique user agents, each tagged by `core/ua_classify.py` as `coding_agent` (Claude Code, Cursor, Codex, Cline, Windsurf, Continue, mcp-client, fastmcp, `python-httpx` with an mcp hint…), `browser`, `script` (curl, python-requests, httpx, node-fetch, Go-http-client), or `unknown`. Write the classifier as an ordered list of `(pattern, label)` so adding agents is a one-line change.
- Top 20 queries.
- Error rate.
- Optional: a status line "last successful upstream call N minutes ago".
