# T05 — Machine-readable presence

Owner: Opus B (growth)
Depends on: T01
Unblocks: T11

## Goal
Everything an agent or registry crawler reads to discover the service. Placeholders for the domain: use `https://api.foretak.dev` and `https://github.com/foretak/registry-mcp`; note in `HUMAN_TODO.md` (create it) that these must be search-replaced if the human's Step 1.1 lands on a different name.

- `static/llms.txt` — under 40 lines: what it is, the MCP add command, the curl example, link to llms-full.
- `static/llms-full.txt` — full endpoint and tool documentation written for an LLM reader: for each endpoint/tool, what it's for, when to use it, example call, example response, what to do on each error code.
- `static/index.html` — single static homepage. Order: h1 + one sentence, then the `claude mcp add` command, then the curl example, then JSON-LD `WebAPI` block (`@type: WebAPI`, `documentation`, `provider`, `termsOfService`), then GitHub link. No marketing copy above the code.
- `server.json` — manifest for the official MCP registry. **Fetch the current schema live from registry.modelcontextprotocol.io (or the modelcontextprotocol/registry GitHub repo) before writing**; validate against it; record the schema URL and date in the file's `$schema` and in `HUMAN_TODO.md`.
- `KEYWORDS.md` — the canonical alias list (`brreg`, `brønnøysund`, `brønnøysundregistrene`, `enhetsregisteret`, `organisasjonsnummer`, `orgnr`, `org.nr`, `norway company lookup`, `norwegian business registry`, `foretak`, `company registry`, `mcp`) with instructions on where each must appear (package description, README first line, tool docstrings, repo topics, server.json).
- Append to `NORBIZ_SPEC.md` a short section "Serving static files": `/` serves `index.html`, `/llms.txt`, `/llms-full.txt`, `/server.json` — T06 implements it.

## Files you own
`static/`, `server.json`, `KEYWORDS.md`, `HUMAN_TODO.md`, the "Serving static files" section of `NORBIZ_SPEC.md`.

## Files you must not touch
`core/`, `registries/`, `api/`, `mcp/`, `tests/`, `DECISIONS.md`.
