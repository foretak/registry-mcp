# T15 — Second country: United Kingdom (Companies House)

Owner: Orchestrator (coordination); sub-tasks below have their own owners.
Depends on: T14 (launched 2026-09-04)
Target: ≤ 2 weeks wall-clock per the guide's Step 12. If it takes longer, the core abstraction is wrong and Opus A fixes `core/` before country three.

## Why UK first
Free REST API with an instant key (developer.company-information.service.gov.uk), excellent docs, and an English-speaking developer audience. Denmark (CVR) needs an access application with a multi-day wait — it's T16, started in parallel.

## Ground rules (from D-001/D-008 and the T10 review)
- Everything UK lives in `src/registry_mcp/registries/gb/` (ISO-3166-1 alpha-2 is **GB**, not UK). `registry = "companies-house"`.
- One import line in `registries/__init__.py`. **Zero edits to `core/`, `api/`, `mcp/`** — if the module needs one, that is the finding: stop, write it in `PROGRESS.md`, and the architect decides.
- Known carry-over: seven tests hard-code the country list and `test_unsupported_country` uses `SE`. Those tests may be updated (they're the suite's, not core's); switch `test_unsupported_country` to `ZZ`.
- Same contract as Norway: `CompanyReport`, `SearchResult`, `DeadlineReport` (via `Registry.deadline_report`), `ValidationResult` (via `Registry.validate`), `format_id`, `aclose`, `rules_markdown`. Unknown is `None`, never guessed (D-004/D-009/D-011). Every field verified against live JSON before the mapping is final; mark `VERIFY` until then.
- API auth: Companies House uses HTTP Basic with the API key as username, empty password. Env `COMPANIES_HOUSE_API_KEY`. Without a key the registry must raise `RegistryError(upstream_error)` with a hint naming the env var — never crash at import. Rate limit: 600 requests / 5 minutes per key — respect it (simple token bucket in the client) and cache aggressively (D-006).

## Sub-tasks

### T15a — Architect (Opus A): `UK_SPEC.md` + decisions
- Write `UK_SPEC.md` mirroring `NORBIZ_SPEC.md`'s structure: field mapping table (`company_number`, `company_name`, `company_status`, `type`, `date_of_creation`, `registered_office_address`, `sic_codes`, `accounts.next_due`, `accounts.accounting_reference_date`, `confirmation_statement.next_due`, `has_charges`, `has_insolvency_history`, `previous_company_names`, `jurisdiction`, `links.officers`…), endpoints (`GET /company/{number}`, `GET /search/companies?q=`, `GET /company/{number}/officers` — deferred like NO roles), status derivation (active / dissolved / liquidation / receivership / administration / voluntary-arrangement / converted-closed), legal-form table (ltd, plc, llp, private-unlimited, charitable-incorporated-organisation, community-interest-company, sole traders are NOT registered — note it), **identifier rules**: 8 characters, digits or prefix+digits (`SC`, `NI`, `OC`, `SO`, `NC`, `LP`, `SL`, `FC`…), zero-padding of short numeric input, no check digit → `validate_id` normalises and checks shape only.
- **Deadlines with `today`** — the differentiator. Use the dates Companies House *gives* (`accounts.next_due`, `confirmation_statement.next_due`) as authoritative when present, and compute only what's derivable and certain: annual accounts (9 months after ARD for private companies, 6 for public), confirmation statement (14 days after the review period end), first accounts after incorporation (21 months). Corporation tax (HMRC: payment 9 months + 1 day, CT600 12 months after period end) — include only if confident, else `VERIFY` and omit. UK weekend/bank-holiday roll-forward: note that Companies House deadlines do **not** roll forward (a Sunday deadline is a Sunday deadline) — check and document; `core/rules/common.py` helpers take holidays as a parameter, so pass an empty set if so.
- Numbered test list (the implementer builds exactly that). Confidence anchors per D-005. Append D-015+ to `DECISIONS.md` for anything new (e.g. "GB is the code; UK is accepted as an alias at the API layer? — decide: recommend NO alias, strict GB").
- Done-check: `UK_SPEC.md` exists; `mypy`/`ruff`/`pytest` still green (no code yet); decisions appended.
