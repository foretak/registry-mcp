## 1. Sweden joins `financials` everywhere an agent reads (D-042(d)(2))

The facts, all from the merged code and D-047(f) — check each against the source before writing it:

- `financials` is declared by **`NO` and `SE`** (`registries/se/__init__.py::supported_includes` is
  `{"filings", "financials"}`); `GB` does not declare it, so `include=["financials"]` for `GB` is `bad_request`.
- **Norway**: Regnskapsregisteret's open key figures, one period (the endpoint holds no history), the same fetch
  as `filings` (D-043(h)). Unchanged from T46's text — keep it.
- **Sweden**: read out of the entity's **own filed annual report** — the K2 inline-XBRL document Bolagsverket's
  document API serves (`/dokumentlista`, shared in-flight with `filings`, then one `/dokument`); one period, the
  most recent filed report; figures cached 30 days on the immutable `dokumentId`; the document is parsed and
  discarded, never stored; `currency` comes from the document's own unit; the block is **entity accounts, never
  a group** (`consolidated: false` is a fact about the K2 channel, not an inference about the company);
  **K3 filers were not observed** in the free document list — four K3-sized companies returned empty lists —
  so in practice the channel serves smaller aktiebolag filing digitally under K2, and a K3 document, if one
  arrives, gets `accounting_framework: "K3"` with `scope`/`consolidated` left `None` and a `notes` caveat;
  `total_comprehensive_income` and `liabilities` are always `None` for Sweden (no concept exists for either;
  no arithmetic invents one); a company whose document list is empty gets a **present** block with
  `periods: []` — the two-level nullability T46's text already explains.
- **Britain**: does not declare it, and **the reason is now the register's own, not ours** (D-047(f)): the
  accounts of the companies that matter are filed on paper or as PDF, the machine-readable (iXBRL) mandate is
  1 April 2028 with a profit-and-loss publication opt-out for small and micro companies, and no British
  document carries a balance-sheet total this block could relay. Say that in one clause, not a paragraph.
- D-043(e) stands: no ratio, indicator or verdict, and Bolagsverket's own tagged `Soliditet` is never read
  (the recon found the same quantity tagged `−0.1761` in one report and `−17.61` in another).
