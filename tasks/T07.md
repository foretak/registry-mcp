# T07 — MCP server

Owner: Sonnet 3
Depends on: T06
Unblocks: T08

## Goal
`mcp/server.py` with FastMCP:

Tools (docstrings must naturally include the alias keywords from `KEYWORDS.md` — e.g. "Look up a Norwegian company in Brønnøysundregistrene / Enhetsregisteret by organisasjonsnummer (orgnr)…"; every docstring says when to use the tool and what to do on error):
- `lookup_company(id: str, country: str = "NO") -> CompanyReport`
- `search_company(name: str, country: str = "NO", limit: int = 10) -> list[SearchHit]`
- `company_deadlines(id: str, country: str = "NO", today: str | None = None) -> list[Deadline]`
- `validate_company_id(id: str, country: str = "NO") -> dict`
- `list_countries() -> list[dict]`

Resource `registry://rules/{country}` — returns the human-readable rules summary for that country (org forms, status logic, deadlines) so an agent can read them without calling tools.
Prompt `explain_company(id, country="NO")` — instructs the model to call lookup + deadlines and summarise for a non-expert.

Transports: Streamable HTTP mounted at `/mcp` on the same FastAPI app as T06; stdio via `python -m registry_mcp` and a console script `registry-mcp` (add to `pyproject.toml` `[project.scripts]` — this is the one pyproject edit you're allowed).

Errors: catch `RegistryError` and return the D-007 shape as tool error text, never a bare traceback.
