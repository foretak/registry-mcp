# Part A — the models and the mapper (start now; nothing blocks it)

Everything in Part A goes into the **existing** `src/registry_mcp/registries/no/accounts.py`, beside
the `FiledDocument` / `FilingHistory` stand-ins already there. It maps the **same payload** those
stand-ins map, so it belongs in the same module and re-reads the same parsed body. **Do not create a
second module and do not add a second fetch.**

## A1. Four model stand-ins

Copy `DECISIONS.md` D-043(c) field-for-field: `IncomeStatement` (9 floats), `BalanceSheet`
(10 floats), `FinancialPeriod`, `FinancialSummary`. Same `_Base` (`extra="forbid"`) the module
already defines; `provenance` typed to the module's existing `FilingProvenance` stand-in, not to
`core.models.SourceRef`. These are stand-ins for the future `core.models` classes exactly as
`FiledDocument` is, so that wiring is a rename.

**`FinancialPeriod.currency` is `str` with no default.** That is deliberate and load-bearing
(D-043(d)): a currency-less figure must be unconstructable, not merely discouraged. `valuta` was
present on 573 of 573 observed responses; if it is ever absent, that period is **skipped** and a
`notes` sentence says one filed period could not be carried because the register published no
currency for it.

Every numeric field's `description` must state, in these terms: **`None` means the register did not
publish this line for this filing — never zero — and the register is inconsistent about when it
states an explicit zero** (D-043(f), with the two live examples). Do not paraphrase this into
"unknown".

`unaudited`'s description must say its `True` state was never observed in 573 payloads, that its
meaning is therefore not vouched for, and that a `False` here is not an assertion that the accounts
were audited (D-043(g)).

## A2. `map_regnskap_financials(payload, orgnr, *, cached, fetched_at) -> FinancialSummary`

Pure, synchronous, no I/O — the same convention as the module's existing `map_regnskap`. Same
argument shape, same `FilingProvenance` construction (`source`, `source_url`, `license`,
`fetched_at`, `cached` identical to what `map_regnskap` builds — see D-043(h)(2)).

Field mapping, from the comment column of D-043(c). Two traps:

- **`sumInnskuttEgenkaptial` is spelled that way by the register.** It is not a typo in this brief.
  Read the key exactly as written; do not "fix" it and do not fall back to a corrected spelling.
- **An empty nested object (`"langsiktigGjeld": {}`) yields `None`, not `0.0`.** So does a missing
  one. Use the same tolerant reader for every leaf; never `dict.get(k, 0)`.

`consolidated` is derived from `scope` (`regnskapstype`) by a **committed table in this module**:
`{"SELSKAP": False}`, plus `"KONSERN"` → `True` **only if you observe it live** — it was never
returned in 573 responses, including for every parent company tried. A word the table does not
contain yields `None`, never `False` (D-025(d)). If you do not observe `"KONSERN"`, ship the
one-entry table and say so in a comment.

`income_statement` / `balance_sheet` are `None` when the register published no line in that
statement at all; otherwise present with the lines it published.

`periods` is sorted by `period_end` descending. Norway returns exactly one element, always; the list
exists for a register that returns several.

## A3. `notes`, ruled rather than invented

**Unconditional on a non-empty block** (three sentences):

1. The comparability sentence (D-043(d)): figures are denominated in the stated `currency`, prepared
   under the stated `accounting_framework`, and are not comparable across companies or borders
   without regard to both. Nothing here converts, restates or annualises anything.
2. The one-period sentence, and the preview sentence — reuse the strings `map_regnskap` already
   holds (`_ONE_PERIOD_NOTE`, `_PREVIEW_NOTE`) rather than writing near-duplicates. Both blocks
   carrying them is intended (D-043(h)).

**Conditional:**

3. **When `total_assets` and `total_equity_and_liabilities` are both present and differ** — name
   both values and the gap. This is the *only* arithmetic permitted in this block and its output is
   a sentence, never a figure (D-043(e)). Neither number is edited, reconciled or dropped. Expect it
   on roughly 7.5% of filings.
4. `currency != "NOK"` — say so plainly; a caller comparing two Norwegian companies will not expect
   it. 12 of 358 observed filings.
5. `small_entity` — the reduced-disclosure regime (regnskapsloven § 1-6): fewer figures exist and
   those that do permit simplifications. **Not** a distress signal; 315 of 358 filings.
6. `audit_exempt` — no independent auditor checked these figures (aksjeloven § 7-6 opt-out, lawful
   below the thresholds). 65 of 358.
7. `liquidation_basis` — an *avviklingsregnskap* (aksjeloven § 16-10): realisation basis, not going
   concern, over a final period. **Do not restate the winding-up itself** — `CompanyStatus` already
   carries it on the company record.
8. `unaudited` is `True` — say the register set a flag whose meaning this project has not been able
   to verify, and do not translate it into a claim about the audit.

Cite statutes the way `registries/no/rules.py` already does. If you cannot source a citation from
what is already in the repo, write the note without the section number rather than guessing one
(D-009).

## Out of scope (both parts)

- **Widening `FiledDocument`.** D-043(b) declined it explicitly. `tasks/T37.md` and `tasks/T31.md`
  depend on that model's current shape; changing it here breaks two other agents' work.
- **Any derived ratio, indicator or verdict** — `equity_ratio`, `current_ratio`, `net_debt`,
  `working_capital`, `is_solvent`, a risk score, a trend, a year-on-year change. D-043(e) rules them
  out on three independent grounds, the strongest being that the register relays filings whose own
  totals do not balance. The single permitted comparison is A3's reconciliation note.

  We hold no FX rate and choosing one requires inventing a date (D-009).

  D-042(f)), `/oppdateringer`, `/lastned`, Løsøreregisteret. This task adds **no** upstream call:
