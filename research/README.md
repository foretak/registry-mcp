# research/ — the distilled research layer

What is here: the agent primer and the seven folder summaries from the
registry-mcp research library built on 2026-09-05 (market and buyers, registers
landscape, regulation drivers, MCP and agent ecosystem, competitors, accounting
and finance software, product improvements). Every claim in these summaries
cites a URL and a fetch date.

What is not here: the ~150,000 words of sourced evidence files behind the
summaries. They live outside the repo at `~/research/registry-mcp/` on Kim's
machine (rules in `BRIEF.md`, file list in `INDEX.md`), because they include
saved third-party texts that do not belong in a public repository.

How to use it: an agent starting work on this project reads
`AGENT_PRIMER.md` first, then the summary relevant to its task, and goes to the
full library only when it needs the underlying source. Figures are as of
2026-09; re-verify anything older than a quarter before acting on it. Extend
the library under the same BRIEF rules rather than with ad-hoc notes.
